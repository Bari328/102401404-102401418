# 校园失物招领（Campus Lost & Found）

2026 秋 软件工程 · 第二次结对作业。基于第一次结对作业的原型设计，实现「发布信息 — 浏览或搜索 — 查看详情 — 联系发布者 — 更新状态」的完整闭环。

纯 HTML / CSS / JavaScript 实现，**不需要安装任何依赖，不需要起服务器**，用 Chrome 打开 `index.html` 即可运行。

---

## 一、目录结构

```
campus-lost-found/
├── index.html              首页：搜索入口、分类快捷入口、信息流、悬浮发布按钮
├── search.html             搜索页：搜索历史、大家都在找、结果筛选、无结果引导
├── detail.html             详情页：物品信息、发布者联系方式、状态标记入口
├── publish.html            发布页：选择寻物 / 招领，填写表单并校验
├── success.html            发布成功页
├── mine.html               我的发布：统计、筛选、标记完成、删除
│
├── css/
│   ├── base.css            设计变量、重置样式、通用组件（按钮 / 卡片 / 标签 / 弹层）
│   └── pages.css           各页面专属样式
│
├── js/
│   ├── core.js             纯逻辑层：配置、工具函数、表单校验、搜索筛选、状态变更、统计
│   ├── repo.js             数据仓库层：增删改查 + localStorage 读写（可降级为内存）
│   └── ui.js               浏览器 UI 层：图标、页面外壳、物品卡片、弹层、图片压缩
│
├── test/
│   ├── framework.js        极简测试框架（describe / it / assert），浏览器与 Node 通用
│   ├── tests.js            51 个单元测试用例
│   ├── test.html           在浏览器里跑测试（打开即可）
│   └── run.js              在命令行里跑测试（node test/run.js）
│
└── README.md
```

### 三层结构为什么这样分

| 层 | 文件 | 职责 | 依赖 |
| --- | --- | --- | --- |
| 表现层 | `*.html` | 渲染页面、绑定事件 | 依赖 core + repo + ui |
| 业务逻辑层 | `js/core.js` | 校验、构造信息、搜索筛选、状态变更、统计。**全是纯函数，不碰 DOM 和 localStorage** | 无依赖 |
| 数据仓库层 | `js/repo.js` | 持有信息列表，负责读写 localStorage | 依赖 core |

把业务逻辑做成纯函数，是为了让它能脱离浏览器被单元测试直接调用；`repo.js` 的存储介质是注入的，传 `null` 就退化为内存模式，因此 Node 里也能测。

## 二、如何运行

### 1. 运行网页

1. 把整个 `campus-lost-found` 文件夹下载到本地（保持目录结构不变）。
2. 用 **Chrome** 打开 `index.html`（双击即可，不需要本地服务器）。
3. 首次打开会自动写入 5 条示例数据，直接就能试用。

> 数据存在浏览器的 localStorage 里，关掉浏览器再打开依然在。想恢复初始示例数据，在 Chrome 控制台执行 `localStorage.clear()` 后刷新。

### 2. 跑单元测试

两种方式，任选其一：

```bash
# 方式一：命令行（不需要安装任何依赖）
node test/run.js

# 方式二：用浏览器打开 test/test.html，页面会自动运行并显示结果
```

预期输出：`共 51 个用例：通过 51 个，失败 0 个`。

## 四、附加设计的几个小功能

1. **关键词高亮**：搜索结果的标题里，命中的关键词会用底色标出来，用户一眼就知道为什么这条被搜出来。
2. **一键复制联系方式**：详情页打开联系方式弹层后可以直接复制，不用手抄微信号。
3. **搜不到时的「换个说法」**：搜「蓝色充电宝」没结果时，会推荐「充电宝 / 移动电源 / 数据线」等同义或相关词，而不是只丢一句「没有结果」。
4. **照片自动压缩**：上传的图片先压到最长边 720px 再存，避免 localStorage 被几张大图写满。
5. **30 天有效期**：每条信息都显示还剩几天自动下架，避免过期信息一直占着搜索结果。
6. **存储降级**：localStorage 不可用或写满时不报错，自动退化为内存存储，页面依然能用。

## 五、技术说明

- 未使用任何第三方框架或 CDN，所有图标都是内联 SVG。
- 页面之间通过 URL 参数传值（如 `detail.html?id=xxx`），数据统一存在 localStorage，因此各页面之间不需要共享内存状态。
- 所有用户输入在写入 `innerHTML` 前都经过 `escapeHtml` 转义，避免 XSS。
